# Pey-Man Goals

## North Star

Produce a fitness tracker that runs cleanly in MATLAB Online, turns MATLAB Mobile sensor data into useful workout feedback, and is easy to explain in a short English demo.

## Competition Definition of Done

- MATLAB workflow runs from a clean checkout.
- At least one useful fitness metric is computed.
- At least one clear visualization is produced.
- Code or live script is readable and organized.
- The final explanation covers problem, method, result, and limitations.
- Final submission contains only relevant project files.

## Scoring Targets

### Model Work - 70 points

- Creativity: show an original tracker angle, not just a copied starter example.
- MATLAB mastery: use tables/timetables, functions, plots, and clean data processing.
- Functionality: run without errors on the included sample data and team data.
- Readability: keep the workflow understandable for judges.
- Data visualization: include labeled, interpretable plots.
- Model making: move from raw sensor data to a viable model.
- Advanced model making: add machine learning or a comparable advanced step only after the baseline is stable.

### Presentation - 30 points

- Creativity: make the demo memorable and practical.
- Quality: clean visuals, clear result, no messy setup.
- Concept: explain why the tracker output matters.
- Clarity: keep the story simple enough for non-experts.

## Practical Build Path

1. Baseline: load sensor data and reproduce a working starter output.
2. Tracker metric: choose one primary metric such as steps, distance, activity type, intensity, or workout quality.
3. Visualization: produce a judge-readable plot and summary output.
4. Upgrade: add one feature that improves score without risking the baseline.
5. Demo: prepare a short English walkthrough under 5 minutes.

## Constraints

- No hardcoded machine paths.
- No private raw personal data in commits.
- No feature work that breaks the working baseline.
- Commit and push after every meaningful step.
- The repository is private during work; submission may require a public or shareable link later.
