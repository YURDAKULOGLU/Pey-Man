# Shared Chat Brief

Use this as the first message when opening a team chat or AI shared chat.

```text
We are working on a MathWorks Hackathon / BEST Istanbul Yildiz project: create a fitness tracker with MATLAB Online and MATLAB Mobile.

Project goal:
- Use phone sensor data to calculate or infer useful fitness metrics.
- Possible outputs: steps, calories burned, distance walked, flights climbed, workout intensity, activity classification, or workout quality.
- The final result must be easy to understand and presented in English.

Available starter files:
- ExampleModel.mlx
- ExampleData.mat
- ActivityLogs.mat
- timeElapsed.m
- Instructions.pdf
- GradingRubric.pdf
- Welcome Presentation.pdf

Judging:
- MATLAB model: 70 points
- Presentation/demo: 30 points
- ML/deep learning can improve the score, but the model must run cleanly and be readable.

Submission:
- Devpost project is required.
- Project must be hosted through a public or shareable repository/location such as GitHub, MATLAB Drive, Google Drive, File Exchange, or similar.
- Demo must be under 5 minutes and may be a video, slide deck, essay, or other clear presentation format.

Immediate task:
Help us choose a focused fitness tracker concept, divide team roles, and outline the MATLAB implementation plan using the starter files.
```

## Suggested Roles

- Programmer: model implementation, data processing, testing.
- Athlete/data collector: phone sensor recording and repeatable test activities.
- Presentation lead: English demo, visuals, Devpost write-up.
- Integrator: keeps files organized and makes sure the submission runs.

## First Discussion Prompts

- What fitness metric can we compute reliably with phone sensors in the available time?
- What data do we need to collect ourselves?
- What will be our simple baseline model?
- What one advanced idea can we add without risking the deadline?
- What visuals will make the result obvious to judges?
