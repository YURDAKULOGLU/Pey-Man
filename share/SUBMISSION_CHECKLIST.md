# Submission Checklist

## Before Coding

- [ ] Team agrees on a single tracker concept.
- [ ] Team decides which phone sensors to use.
- [ ] Starter example opens in MATLAB Online.
- [ ] Everyone knows where the project files are stored.

## Model

- [ ] Data loads without errors.
- [ ] Script or Live Script runs from a clean folder.
- [ ] Output metric is clear and useful.
- [ ] Code is readable and organized.
- [ ] At least one meaningful plot or visualization exists.
- [ ] Optional advanced feature is attempted only after the baseline works.

## Presentation

- [ ] Demo is in English.
- [ ] Demo is under 5 minutes.
- [ ] Problem, method, output, and result are easy to follow.
- [ ] Visuals are included.
- [ ] Limitations or assumptions are stated briefly.

## Devpost / Share Link

- [ ] Devpost project exists.
- [ ] Public/shareable project link is ready.
- [ ] Demo file or link is attached.
- [ ] Only one team submission is made.
- [ ] Final package does not include private or unrelated files.
