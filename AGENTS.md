# Pey-Man Agent Instructions

Project: MATLAB Mobile fitness tracker hackathon package.

## Rules

- Commit and push after each meaningful step.
- Keep this repository self-contained; avoid machine-specific absolute paths.
- Do not commit credentials, private phone logs, personal identifiers, or unrelated files.
- Optimize for the rubric before adding novelty.
- Keep one working baseline at all times.

## Workflow

1. Read `README.md`, `docs/Instructions.pdf`, and `docs/GradingRubric.pdf`.
2. Maintain `PLAN.md` as the current project plan.
3. For major work, leave evidence in `RESULT.md` or a dated note under `share/`.
4. Verify with MATLAB Online or record exactly why local verification was not possible.
5. Push after each commit so the private GitHub repo stays current.

## Competition Priorities

1. Working tracker output.
2. Clear visualizations.
3. Clean readable MATLAB workflow.
4. One advanced feature if the baseline is stable.
5. Demo under 5 minutes.
