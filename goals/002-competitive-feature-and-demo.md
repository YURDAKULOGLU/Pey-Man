# Goal 002 - Add Competitive Feature and Demo Package

## Objective

Improve the working baseline with one scoring feature and prepare a concise demo/submission package.

## Prerequisite

`goals/001-onboard-and-baseline.md` must be complete and pushed.

## Required Work

1. Choose one feature that improves score without risking the baseline:
   - activity classification,
   - workout quality score,
   - peak-based step detection,
   - model comparison,
   - improved visualization/story.
2. Implement it in a way that stays readable for judges.
3. Add or update visual outputs.
4. Prepare demo notes under 5 minutes:
   - problem,
   - data,
   - method,
   - result,
   - limitation,
   - next step.
5. Update submission checklist.

## Constraints

- Keep the baseline path intact.
- Do not commit private phone data unless explicitly approved.
- Favor one polished feature over several fragile experiments.
- Commit and push after each meaningful step.

## Completion Evidence

- Feature implementation committed.
- Demo notes committed.
- Submission checklist updated.
- Verification note committed.
- Remote `origin/main` contains the final commit.
