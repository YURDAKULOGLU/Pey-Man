# Goal 001 - Onboard Pey-Man and Build Baseline

## Objective

Learn this repository, extract the hackathon requirements, and produce a verified baseline MATLAB fitness tracker workflow.

## Scope

- Repository root: `C:\Projeler\Pey-Man`
- Source starter package: `source/matlab-mobile-fitness-tracker-master`
- Official requirements: `docs/Instructions.pdf`, `docs/GradingRubric.pdf`
- Project guidance: `GOALS.md`, `PLAN.md`, `docs/RUBRIC_CHECKLIST.md`

## Required Work

1. Read the project docs and identify the starter workflow.
2. Inspect the MATLAB files and data assets.
3. Create or adapt a baseline MATLAB script/live-script path that:
   - loads available sample data,
   - computes one useful fitness metric,
   - produces one clear visualization,
   - can be explained to judges.
4. Add short notes explaining how to run the baseline.
5. Verify the baseline as far as the environment allows.

## Constraints

- Do not remove starter files.
- Do not hardcode absolute local paths.
- Do not add advanced ML before the baseline is working.
- Commit and push after each meaningful step.

## Completion Evidence

- Baseline file committed.
- Run instructions committed.
- Verification note committed.
- Remote `origin/main` contains the final commit.
